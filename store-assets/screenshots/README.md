## על הריפוד

המקור ביחס 1:2.17, גבוה משתי החנויות (אפל 1:2.17→1:2.168, גוגל מגבילה
ל-1:2). במקום לחתוך תוכן — ולאבד את הכותרת או את התפריט התחתון — רופדו
הצדדים בצבע שנדגם מקצוות התמונה עצמה. הריפוד ממשיך את הרקע הקיים
ולכן אינו נראה כמסגרת. `scripts/` אינו נדרש: הקוד יושב בהיסטוריית הגיט
של הקומיט הזה.
